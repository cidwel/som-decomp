# Shared ground, terrain and movement publication

Five reserved complete ranges contain 1,267 unique bytes: C0D2E0–D479 (410), the shared C0D47A–D481 contact-clear tail (8), C0D482–D5BF (318), C0D74F–D88F (321) and C0D890–D961 (210). Existing NPC226 and Hero641 sources are excluded. All 624 own instruction starts and every immediate M/X width are observed in passing complete original comparisons. Five readable sources independently assemble to the exact ROM bytes; `data/map_motion_shared_source_audit.json` records the source and evidence hashes.

Ground handling first consumes the contact mask: blocked axes are cleared, contact-derived signed velocities are restored from E03A/E03B, and only the persistent contact bit survives. Inhibition, status, global motion and selected-actor guards precede animation slowdown. Tile effects dispatch oscillating ground, signed currents, presentation or a ground-triggered event. The event path transfers actor identity, clears both live and scratch velocities and the consumed event word, decodes the packed event id and invokes the existing full event-command service.

Pose handling distinguishes NPCs from the three hero slots. It retains forced pose, inhibition and status guards; facing uses the original signed live velocity rather than the adjusted scratch movement. Idle, contact, special-ground and fast-motion poses preserve the original accumulator exchanges. Status motion caps signed magnitude while preserving direction. The new adapter masks every M8 accumulator result to its low byte and derives the one-bit ROL carry from that byte; this fixes previously untested stationary/status directions without modifying the frozen Hero641 model or evidence.

Terrain handling selects the actual map layer/attribute pointers, evaluates the CF01, FF/E1, F1/4E and D0/party guards, and calls the frozen point-step query when required. Redirected movement temporarily clears the other axis and rechecks the live party window. A rejected recheck clears the velocity word and returns carry; an accepted recheck restores the saved axis before publishing the destination tile's type/layer. Coordinate arithmetic retains the signed magnitude encoding and toroidal bounds.

Publication inherits a partner's layer for an uncontrolled hero where required, publishes the ground attributes only when the terrain word changes, moves each coordinate and derives the camera step from the original window comparisons. Horizontal NPC movement clears DP84; vertical NPC movement branches directly to RTS, retaining DP86 and M16. This asymmetry is explicitly implemented in the new adapter and was discovered by the direct negative/wrapped NPC comparisons.
