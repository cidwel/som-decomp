# Public boss pool update

C20003 jumps to C201F9. Its 65-byte body saves the caller status, direct page and data bank; establishes D0200/DB7E and 16-bit registers; runs the complete nine-slot boss pool; then checks the pending actor pointer at0360 and the pool lock byte02CA. A permitted request calls C0001B with the actual Y returned by the pool. On success it clears the actor control word60, masks the actor pointer to its relative slot, and executes01800F. Both success and rejection consume0360. Finally it restores caller context. Together these entries comprise68 instruction bytes, with no new tables.

`boss_public_pool_update.PublicPoolUpdate` composes the frozen Native58 pool, actual animation/combat/children and full native cast request/API. The outer native frame places pool execution seven bytes below the incoming stack: three for JSL, one status, two direct page and one data bank. Nested native calls use their existing stack adapters. It does not reload or normalize Y for the request.

The new checker prepares32 directed contexts: both public entries, an empty boss pool, pending hero casts with sufficient and insufficient MP, and a Native58 initial world. Caller D0/0300, DB42/7F, M8/M16, X16 and four status combinations exercise restoration. Model-only preflight passed all32, including eight positive requests and eight rejections. This is preparation, not original execution evidence or source credit.

Original comparison passed32 directed calls on the first capture, following a one-case smoke. Eight queued casts were accepted and executed through the full API, and eight were rejected for insufficient MP. Full WRAM outside the observed native stack, returned CPU registers/status, restored D/DB/S, peripherals, IRQ/ACK state and ordered audio agree. Both entrypoints and all32 own instruction starts are covered; dependencies and final capture hashes are recorded in `data/boss_public_pool_update_audit.json`. The model, checker and reports are now frozen.

The pool clears02CA before its pass. These worlds do not produce a nonzero lock during that pass, so the wrapper's defer-on-lock edge has not been exercised with a native producer. Context coverage is directed rather than exhaustive: four status combinations, X16 only, binary arithmetic. Independent source recovery remains root's integration step. This does not claim a whole fight, render loop or console timing.
