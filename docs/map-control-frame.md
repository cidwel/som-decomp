# Main map-control coordinator

`tools/map_control_frame.py` reconstructs the readable control flow of C0B4FE–B69B,414 bytes. The terminal C0B630–B69B tile-event consumer,108 bytes, already has independently verified source. This closure adds306 unique source bytes and represents the whole414 as a component over those two contiguous blocks.

The model follows overlay requests, parity-dependent screen blinking, deferred audio publication, mode-seven scene requests, world-map restarts, door-action continuations, saved-map return requests and the existing three-hero tile-event consumer. It composes the frozen overlay, complete mode-seven scene, door and event models. Return-snapshot register effects are reconstructed from the existing mnemonic source rather than using the older memory-only helper.

The two nonlocal transfers are explicit boundaries at C0B03F and C08038. They are real destinations of the decoded body, not invented returns; their subsequent main loops are separate work. Original comparisons must retain CPU/context, WRAM/SRAM, peripheral state, ordered I/O and occupied stack evidence, including the actual map NMI for the overlay path and the complete C64000 scene call.

The complete original comparison executes622 explicit caller cases: all256 blink bytes with both frame parities, overlay gates, deferred sounds, scene/fade gates,32 door actions, three selected return heroes and tile-consumer guards. All pass:563,495 original instructions and2,034 PC/M/X states, with full WRAM/SRAM, registers, context, peripheral state and ordered audio writes retained. `data/map_control_frame.json` and its coverage capture freeze the actual evidence and recursive dependencies.

The caller stack starts at01FF, as established by the existing B03F main-loop initializer, with an inactive menu publication flag1D04=0. The frozen proof's scope text names that initializer B025 by mistake; the actual B03F mnemonic source contains `LDX #$01FF; TXS`, and the tested stack value is correct. An earlier diagnostic used1F00, overlapping the scene audio workspace and corrupting its return address; that diagnostic is rejected. The corrected scene path and actual audio-port adapter pass the complete comparison. Only addresses actually written by original stack pushes are excluded as call scratch, preserving intervening RAM for comparison.

`data/map_control_frame.source_audit.json` independently verifies all142 instruction starts in the306-byte prefix, requires unique observed immediate widths, and assembles every byte exactly. The existing108-byte consumer remains the shared tail. This is an explicit map16-derived caller domain, with software peripheral phase inputs; concurrent active menus, later main loops, arbitrary caller corruption and physical console timing remain outside the contract.
