# Event menu actor eligibility, cycling and selection restoration

`EventMenuActorCycle` reconstructs six full menu dependencies: C06A41 selected actor direction/address (26 bytes), C06B03 controller-binding union (7), C06B0A available/living actor mask (60), C06ADE alternative actor choice (37), C06986 next eligible unbound actor search (106), and C069F0 saved actor/controller selection restoration (81). Total: 317 instruction bytes. These reuse the previously delivered menu selection/palette dependencies without duplicate credit.

Availability removes bound controller bits from the actual cyclic mask table at C06B46, reads the selected actor's complete active/status words, and accepts only active byte 1 with no lethal status high bit. Alternative choice examines its original current and next mask indices before falling back to the next table entry. Cycling preserves the actual bounded four-attempt loop through counter 1820; it skips the current actor, inactive/dead records and bound actors, and returns word 1 on success or word 0 on exhaustion. Selection restoration reconstructs actor/controller indices from saved coordinates, chooses a usable alternative, binds the controller and reads its stored party mode.

C069F0 has no return at the end of its selected 81-byte interval: it falls directly into C06A41, which updates 1844 and returns the selected actor's direction flag. The first nine-entry smoke revealed this missing tail effect in the new model. After adding the literal fallthrough composition, the smoke passed and the first 8,192-call capture passed unchanged. Independent assembly must preserve the contiguous C069F0+81/C06A41+26 relationship; the bodies from C06986 through C06B45 form a contiguous 448-byte component when combined with the earlier selection sources.

The capture includes 256 actor-direction selector bytes, 256 controller-union patterns, all six cyclic ROM mask indices with all 512 combinations of low controller-binding/active/dead masks (3,072 calls), and 1,536 contexts each for alternative choice, cycling and saved selection restoration. Each latter family spans all eight binding/active/dead masks over three cyclic origins, with current and saved actor/controller choices varying. Active record low bytes include 0, 1 and 80; randomized record high bytes exercise the original byte comparison after word loading. Six indexed mask values are read from the original ROM at runtime; no payload is saved. The controller-union/availability ABI is M8/X8; entries that normalize widths cover both incoming M/X widths. All use D=0, DB=0 and binary arithmetic.

Full original execution uses zero hooks and interrupts. Comparison checks every WRAM byte outside the observed stack, all CPU registers/flags and S/D/DB, video/arithmetic peripherals and APU acknowledgement state. The capture contains 214 PC/M/X states and 105 current dependency fingerprints. Stack watermarks are 1EF7, 1EFA, 1EFB, 1EFC and 1EFE. All six bodies pass complete instruction-boundary and immediate-width recovery, pending root's independent physical-overlap audit and assembly. The interactive menu driver, vblank/input schedule and opcode 2E remain open; the next dependencies are its complete sprite staging/restoration wrappers and constructor/frame engine.
