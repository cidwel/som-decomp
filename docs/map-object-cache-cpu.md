It compares allCPU registers/flags/widths,S/D/DB,full randomized128KiB WRAM outside129caller-stack bytes,static peripherals and ordered audio. No call hooks bypass instructions.

Record copying preserves the saved coordinate word, low-byte LSR carry and accumulator-high residue after XBA.
