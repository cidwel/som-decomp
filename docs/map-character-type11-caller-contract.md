# Original type11 map-character caller composition

`tools/map_character_type11_caller_contract.py` adds a semantic caller model without new recovered instruction bytes. It composes the existing right-pair contract with the original record preparation and reverse VRAM DMA. `data/map_character_type11_caller_proof_20261013.json` is PASS: eight original no-hook runs, 2,356,444 executed opcodes.

The entry is the genuine initializer loop head C1B1BF, native binary D0/DB7F/M16/X16, DP10=1, a prepared long-return frame and saved DB. The model executes the real PHX and JSR, the entire C1B1D0 record preparation, the frequency branches, channel7 reverse DMA of192 bytes from VRAM into WRAM, the C1C1A1 dispatch, and C1C195 including every helper. For returning cases it also executes the original REP/PLX/INX/INX/DEC, SEP/PLB/RTL suffix. The original JSR saves B1C2 and its return resumes B1C3. No callee is skipped, no CPU/ROM hook is installed, and no DEX or artificial return is introduced.

Four immutable C8 words with type11 high nibble exercise the four frequency fields. They are API fixtures at C8000D, C809B9, C8062F and C80393; they are **not claimed to be native animation descriptors**. Each frequency runs at DP06=8400 and8401. At8400 the real loop executes496 helpers, reaches pointer0000, advances0040 and returns through the caller suffix; the saved descriptor X is restored and advanced by2, DP10 becomes0, and the incoming saved DB is restored. At8401 the original execution remains in C1C199 after1,100 completed helpers, with DP06=9701. This is a continuation bound, not a proof of nontermination.

The comparison covers every CPU field including CPU17, all WRAM including private stack writes, SRAM, VRAM, CGRAM, VRAM/CGRAM ports and latches, DMA registers and base hardware. No stack or scratch ranges are excluded. DMA and PPU effects use the existing loader_ppu/wram_dma bus semantics in both the independent semantic model and original CPU execution; this proves composition within that bus model, not independent hardware timing accuracy. Graphics and descriptor bytes remain volatile and are not saved in the proof.

A separate audit computes the original capped positive count for all64 selector table entries and scans each referenced descriptor. None contains type11. This closes the distinction between an executable type11 caller interface and its absence from the positive native lists. Enabled zero-count selectors do not receive an invented empty-list shortcut: their decrement-loop behavior remains outside this proof, as does eventual reachability through such malformed lists. The full C1B17E entry, interrupts, rendering/timing, arbitrary record/stack overlap and other bank/direct-page domains are not covered here.

The report pins the ROM, eight tool dependencies and six recovered caller/callee source files by SHA256. It awards zero new source bytes and does not modify the existing right-pair proof or catalog status.
