# Event actor fields and controller branches

Seven reconstructed command bodies contribute278 matching instruction bytes: scene parameter33, paused motion34, actor slot branch38, secondary actor byte39, primary actor word3A, binding mask branch3B and leading binding count3C. The checker passed6254 original calls on the first extended capture after a ten-call directed check. Its303 observed PC/M/X states and76 dependency hashes are recorded with the report. Motion31 cleanup and the actual event dispatcher are reused.

33 packs the script argument and parameter into word0600. 34 initializes motion before marking state1C=30 and clearing42. 38 compares D5>>1 with its parameter. 3C counts leading nonzero D9/DA/DB bindings and stops at the first zero. 39 reads an offset/value pair and OR-combines the actor offset with0100+offset; it writes a secondary field byte. 3A writes a whole word at actor40, with current or sixteen positive aligned actor selectors in the verified domain. Unlike39, bit80 is not an NPC alias for3A. Both field writers return without continuing dispatch.

3B translates mask3 to4 and selects D9/DA/DB with the high parameter nibble. Automatic selection reads D9 thenDA thenDB; a negative D9 orDA returns literally to C1F079. Thirty-two fixtures independently reach an identical complete native machine state there: CPU/context, full WRAM and peripheral state are compared across visits. With no interrupt or external mutation, this is a deterministic cycle, not a successful return. The model raises NativeBindingCycle to expose that boundary. Gameplay reachability and behavior under interrupt mutation remain unproven.

Returning cases compare all random WRAM outside the observed stack, CPU registers/flags/widths, stack/bank/direct-page context, peripherals and audio. They cover all256 parameters for six families, seventeen valid3A selectors, four binding contexts and42 actual event core callers. Initial M8/X8, D0/DB7E and binary arithmetic are explicit. Field payloads vary; this is not an exhaustive proof for every memory offset, direct page or invalid actor selector. No hooks bypass original instructions.
