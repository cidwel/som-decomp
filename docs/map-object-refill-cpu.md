# Directional circular map-cache refill

`tools/map_object_refill_cpu.py:Refill` reconstructs complete C0DFD4..E00B (56 new instruction bytes), the actual object refill call used by ordinary actor update. It applies FF/52/E8bit4/count gates, computes the directional loading window from the selected party actor's velocities/facing and scroll state, derives `(BC>>3)+1` scan budget, advances the circular BD cursor with native byte carry/borrow, scales it by16 and tail-enters the complete cache scan. The scan executes actual ordinary/large creation or boss initialization rather than replacing those callees with flags.

The final original comparison exits0 with **1024 complete calls** and **2872 PC/M/X states**:512 synthetic valid caches and512 real map-cache fixtures. It covers counts0..48, valid circular cursors, all velocity sign pairs, zero-velocity facing, nine candidate actor slots, three selected party actors, both incoming accumulator widths, all suppression gates, ordinary/large modes and actual boss fall-through. The sample executes183 ordinary creations,166 large creations and148 boss initialization paths. Synthetic boss caches contain at most one boss to avoid redundant repeated asset initialization; actual lists remain intact. All fixture data is transient.

Full randomized128KiB WRAM outside129 native caller-stack bytes, nine CPU result fields, S/D/DB, arithmetic hardware, static PPU/video/DMA and ordered audio agree without original hooks. Native domain is D0/DB7E/X16/binary, forced blank/VMAIN80, valid selectors, initializer DP02C5 zero and selected viewport extents128. This proves the refill callee in these contexts, not continuous actor frames or arbitrary malformed caches/viewport/timing. The caller C0F4CB, its AI/action coordinator C1D942 and the complete frame-command/piece expansion remain the next root frontier.
