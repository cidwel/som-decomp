# Complete boss-containing map loader CPU composition

`tools/map_object_boss_load_cpu.py:BossLoader` extends the existing readable outer loader with the actual boss eligibility fall-through and complete native resource initialization. It retains the ordinary/large creation paths, cache preparation and scan, then composes the original boss resource command lists and object setup. Original map/object/script/graphics data is read only at runtime.

The new arithmetic adapter in `tools/boss_loader_arithmetic_cpu.py` retains the existing explicit readable command/cache control flow without changing earlier proved modules. At object preparation it publishes the last native terrain multiplication's multiplicand, product and operand-register state (`m1`, `r`, `q`) as well as WRAM results. The previous initializer proof checked the WRAM pointer and DMA/video effects but did not compare the complete hardware dictionary; the initial new comparison exposed that omission. Coordinates are actual cache coordinates masked to seven bits and multiplied by sixteen, with original x/y bounds deciding whether terrain preparation executes. In this proof bounds are1000h; arbitrary bounding contexts and all hardware timing remain open.
