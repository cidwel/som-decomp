Run from the repository root with cc65 tools installed:

```
make verify-source ROM="/absolute/path/to/Secret of Mana (U).sfc"
```

`CA65`, `LD65` and `PYTHON` can be overridden. The verifier assembles into temporary files, then compares the result to the original program decoded from the supplied ROM. The ROM is used only for comparison, not as an assembly input. Temporary binaries are removed. `data/source_build.json` records source fingerprints, per-block result hashes and the matched byte count; it contains no ROM payload.

This is partial matching assembly reconstruction. The boot program is compressed
in the ROM, so matched RAM bytes cannot be divided by ROM size as a valid
progress percentage. The [sparse layout build](../docs/recovered-rom-build.md)
now recomposes known parts of that stream from typed token lengths/distances
and independently assembled RAM literals. Its physical coverage is reported
separately. Remaining literals, assets, the rest of the program and a complete
code-size denominator remain unfinished. The documented-ROM metric is separate.

`manifest.json` lists source addresses and expected sizes. No unresolved region is silently counted as reconstructed, and no original-ROM binary inclusion is used to make a build appear complete.
